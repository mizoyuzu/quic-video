# Browser viewer

The viewer uses the official `@moq/watch` web component. It subscribes to the
same MoQ broadcast published by the iOS app; no OBS or VLC installation is
required.

## Run

Start the relay first, then run the local web server:

```bash
mac/relay/start.sh
web/start.sh
```

Open <http://localhost:8080> in Chrome or Edge. Enter:

- Relay URL: `https://localhost:4443`
- Broadcast path: the value shown in the iOS app's `Broadcast path` field

Use `一覧を更新` to fetch currently announced broadcasts from the relay and
select one without copying the path manually.

The browser must trust the certificate generated by `mac/relay/setup-cert.sh`.
Run that setup on the Mac before opening the viewer if it has not been done.

For a bookmarkable URL, use query parameters:

```text
http://localhost:8080/?relay=https%3A%2F%2Flocalhost%3A4443&name=quic-video%2Fiphone-name-xxxxxxxx
```

The page stores the last-used values in the browser's local storage.
